INSTALL

装 · 装到 WorkBuddy

三组动作：装 Skill、接麦当劳 MCP、开口说一句。跟着 78 秒的视频做一遍就好。

01 装 Skill · 0:0602 接麦当劳 MCP · 0:2203 开口说一句 · 0:47
  1. 01

    装 Skill

    $git clone https://github.com/linzhiqin2003/maimen-gym.git$cd maimen-gym && python3 install.py --target workbuddy

    装好后在 WorkBuddy 的技能页确认 maimen-gym 已开启

  2. 02

    接麦当劳 MCP

    在 open.mcd.cn/mcp 申请麦当劳 MCP Token，然后在 WorkBuddy 的连接器里添加麦当劳 MCP，粘贴配置、点信任。

  3. 03

    开口说一句

    新建任务，直接说：

    「今晚练腿，500 大卡以内，蛋白质 30 克，人民广场附近」

PROMO

27 秒，看懂麦门健身房

Go to Gym 不如 Go to ᗰ：告诉它热量、蛋白质和今天练哪里，最便宜的点法和「只吃馅」的吃法帮你算好。
