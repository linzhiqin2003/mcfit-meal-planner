    INSTALL

    装 · 装到 WorkBuddy

    三组动作：装 Skill、接麦当劳 MCP、开口说一句。跟着视频做一遍就好：前半分钟讲它能做什么，后面一步步装。

    安装教程1:54 · 跟着做一遍
    宣传片0:46

    三组动作

    1. 01

      装 Skill

      macOS · 终端

      $git clone https://github.com/linzhiqin2003/mcfit-meal-planner.git $cd mcfit-meal-planner && python3 install.py --target workbuddy

      Windows · PowerShell

      >git clone https://github.com/linzhiqin2003/mcfit-meal-planner.git >cd mcfit-meal-planner >py install.py --target workbuddy

      装好后在 WorkBuddy 的技能页确认 mcfit-meal-planner 已开启。Windows 上没有 py 命令时换成 python

    2. 02

      接麦当劳 MCP

      在 open.mcd.cn/mcp 申请麦当劳 MCP Token，然后在 WorkBuddy 的连接器里添加麦当劳 MCP，粘贴配置、点信任。

    3. 03

      开口说一句

      新建任务，直接说：

      「今晚 500 大卡以内，蛋白质 30 克，人民广场附近」
