# 3D 食物建模任务书（给 Codex）

项目：Gyᗰ 麦门健身房（健身人群的麦当劳点餐 Skill）。这些 3D 食物用于项目主页的装饰，以及可爱、适合传播的宣传短片。
参考图在 `assets/3d/refs/`（麦当劳中国官方菜单图，只作形体与质感参考，**不得**放进仓库或成品里）。

| 1 | 双层吉士汉堡 | `double_cheeseburger.png` | 每一层是独立物体：顶面包、调料层（几片酸黄瓜 + 一点番茄酱 + 少量洋葱粒）、吉士片、牛肉饼、吉士片、牛肉饼、底面包。要能渲染三种状态：**整份叠好**、**爆炸分解**（各层沿竖轴拉开，间距均匀、略带一点错位和旋转更生动）、**只吃馅**（去掉两片面包，只剩中间） |

## 硬性要求

1. **只做食物本身**：不做任何麦当劳的包装、纸垫（鸡腿参考图下面的黄条纸是品牌元素，不要）、logo、金拱门、「100%纯牛肉」角标。
2. **还原真实质感**，做到"看着就想吃"：面包是光滑、微有光泽的焦糖色（顶部更深、底部浅），有次表面散射；吉士片半透明、边角融化下垂；牛肉饼有颗粒和焦痕；裹粉炸物要有颗粒、凹凸、深浅不一的金黄色。用程序化纹理 + 置换/凹凸，不要依赖外部贴图下载。
3. **颜色**：用 `view_transform = "Standard"`，按需调 `exposure`（AgX 会把金黄洗淡、暖色变粉）。改材质而渲染不变时，先降曝光再判断（漫反射可能已溢出）。
4. **透明背景**：`film_transparent = True`，地面阴影用 shadow catcher，让成品能贴到网页上。每张图合成到三种底色上自查：`#F7F4EE`（暖白）、`#FFFFFF`、`#F2EDE4`（米白），边缘不能有灰边或白边。
5. **可复现**：所有建模和渲染写成 Python 脚本放在 `assets/3d/scripts/`，用 Blender 命令行跑：`blender --background --python <脚本>`（`blender` 换成本机 Blender 可执行文件的路径）。`.blend` 存 `assets/3d/blend/`。
6. **渲染**：Cycles + Metal GPU（本机第一次编译内核约 10 分钟，期间没有日志输出，不是卡死），OIDN 降噪。相机 85mm 左右，三点布光（左上主光 + 补光 + 轮廓光），柔和阴影。面光用 DISK 形状，避免光亮表面出现方形高光。

## 验收（你自己先过一遍再交付）
